# Power BI DEPI

Business intelligence learning workspace from the DEPI Power BI track, focused on data modeling, ETL concepts, analytics thinking, and dashboard-ready reporting foundations.

## Status

Learning repository. This repo is useful as evidence of BI foundations, but the strongest portfolio item remains a finished dashboard with screenshots, model design notes, and business context.

## Topics Covered

- Business intelligence fundamentals
- Descriptive, diagnostic, predictive, and prescriptive analytics
- ETL concepts and data preparation
- Power Query concepts
- Data warehouse vs. staging-area thinking
- OLTP vs. OLAP foundations
- Power BI semantic model concepts
- Dashboard design and KPI communication

## Skills Demonstrated

- BI requirements thinking
- Data preparation concepts
- Analytics communication
- Power BI data modeling foundations
- Executive reporting mindset
